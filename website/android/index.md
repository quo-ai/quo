## Install it

1. Install Quo from [Google Play](https://play.google.com/store/apps/details?id=com.quo.app).
2. Open it. The built-in model is ready, so you can start a chat straight away.
3. Choose more models in **Settings → Models**. Quo offers the ones that run well on your phone.

## What it does

- **Works offline.** Answers come from the model on your phone, so Quo keeps working on planes, abroad and anywhere without signal.
- **Reads your documents.** Ask about a PDF or a text file without uploading it anywhere.
- **Understands your photos** with a model that reads photos.
- **Thinks it through.** Thinking models work a question through step by step, and you can read along.
- **Keeps going in the background,** with a notification, while it finishes an answer.

## Questions

### Is Quo free on Android?

Yes. It’s free with 3 models, including one that sees photos. Premium is a one-time upgrade sold by Google Play: it adds every model, voice input, read aloud, and unlimited chats and memories.

### Does it need the internet?

Only to install it and to download more models. A model comes with the app, so Quo answers with no signal from the start, and your chats stay on the phone.

### Which phones does it run on?

Quo checks your phone’s memory and offers the models that run well on it. The built-in model is small (about 530 MB) and runs on most phones from the last few years.

### Is there an iPhone app?

Not yet: it’s coming soon. Until then, Quo Web runs on a computer in Chrome or Edge.
