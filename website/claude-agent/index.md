# Claude Agent: Claude on your own Claude plan

Claude Agent lets the Quo desktop app use Claude through your own Claude Code sign-in: your Claude Pro or Max plan, an API key or a cloud account. Use it in chat and in Code mode. Quo charges nothing for it and never sees your login.

[Get the desktop app](https://quo.computer/#desktop)[Get Claude Code](https://code.claude.com/docs/en/overview)

- Desktop app: Mac, Windows, Linux
- Your own Claude plan
- Free in Quo

## Set it up

1. Install [Claude Code](https://code.claude.com/docs/en/overview) from Anthropic, then sign in: run `claude auth login` in a terminal.
2. Install the [Quo desktop app](https://quo.computer/#desktop).
3. In Quo, open **Models & storage → Your keys → Claude Agent** and pick a model.

On Windows, install Claude Code with Anthropic’s installer: Quo looks for `claude.exe`.

## What stays yours

- **Your sign-in.** You sign in through Anthropic’s own flow. Quo never reads, stores or passes on your login or a token, and it runs only your own, unmodified copy of Claude Code.
- **Your messages go from your computer to Anthropic,** through your own Claude Code, not through Quo. What you use counts against your own Claude plan.
- **Quo says who it is.** Claude Code marks each request from Quo as coming from Quo.
- **No transcripts left behind.** The transcripts Claude Code keeps for Quo’s conversations are deleted when Quo is done with them, and when Quo quits.

## What it does

- **Chat with the Claude models your plan includes,** with the Thinking levels each one takes.
- **Code mode.** Claude works in your project through Quo’s tools. Claude Code’s own tools are off, so every edit, command, commit and push needs your OK in Quo, as with any model. [How Code mode works](https://quo.computer/code-mode/).
- **Your plan’s limits in view.** The chat bar shows how much of each limit is used and when it resets, and tells you if replies start using usage credits.
- **Photos and documents** you attach go to Anthropic with your message, as with any cloud model. Quo doesn’t add your memories.

## Questions

### Does Claude Agent cost anything in Quo?

No. Quo charges nothing for it. What you use counts against your own Claude plan, or your API or cloud account, as it does in Claude Code.

### Does Quo see my Claude login?

No. Claude Code signs in through Anthropic’s own flow and keeps its own credentials. Quo never reads, stores or passes on your login or a token, and it never learns your account’s email.

### Which Claude plans work?

Whatever Claude Code is signed in with: a Claude Pro or Max plan, an API key, or a cloud provider account.

### Is Quo made by Anthropic?

No. Quo is made by Astra Labs Ltd and isn’t made or endorsed by Anthropic. Claude and Claude Code are Anthropic’s.
