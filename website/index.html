Need more power? Only when you ask.

Quo is local first. For a bigger model, Quo Web and the desktop app offer a free cloud model, or you can connect your own key from OpenRouter, Anthropic, OpenAI and others. Both are clearly marked and only used when you pick them. With your own key, messages go straight to the provider, not through Quo. Models can also search the web when a question needs it, and show the pages they used. You can turn that off in Settings; it is off for offline models unless you turn it on.

Questions.

Is Quo really free?

Yes. Quo Web and the desktop app are completely free, and the phone apps are free with three models. An optional one-time upgrade on the phone unlocks every model and feature. There's no subscription and no ads. See pricing.

Which browser should I use?

Chrome or Edge on a laptop or desktop. They let Quo use your graphics card, which makes replies much faster. Firefox and Safari work, but run on your processor, so replies are slower. If you'd rather not switch browsers, get the desktop app.

What do I need to run Quo?

A computer or phone from the last few years. The smallest model (about 530 MB) runs almost anywhere; bigger models want 8 GB of memory. Quo checks your device and suggests one that fits. See models.

Does anything leave my device?

Not when you use offline models, unless you turn on web search for them. Your chats, files and voice are processed on your device, and chats are saved only there. The only network use is downloading a model, once. If you choose a cloud model, or one with your own API key, those messages go to that model's provider to answer, and Quo marks them clearly. With your own key they go straight to the provider, not through Quo.

Web, desktop or phone: what's the difference?

They're the same private assistant. Quo Web needs nothing installed. The desktop app runs models natively on your graphics card, so it's the fastest and fits the biggest models. Documents and voice work in all of them; photos need a model that reads images, which the desktop and phone apps have. Chats stay on each device.

My computer warns about the desktop app. Is it safe?

The app is built from the open-source code on GitHub by an automated release process. Until our signing certificates are in place, macOS may ask you to confirm it in System Settings › Privacy & Security, and Windows may show “More info › Run anyway”.

How is Quo different from ChatGPT or Claude?

Those run on company servers, so you need an account and a connection, and your chats are stored there. Quo runs on your device, so it works offline and your chats stay yours. Local models are smaller, so for the hardest tasks the big cloud models are still stronger.
