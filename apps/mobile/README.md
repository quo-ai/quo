# Quo for iPhone and Android

The phone apps: Expo SDK 57 / React Native (New Architecture), with [llama.rn](https://github.com/mybigday/llama.rn) running GGUF models on the device.

```bash
npm install
npm run android          # dev build on a device or arm64 emulator
npm run ios              # macOS only; generates ios/ first
npm run typecheck && npm run lint && npm test
```

- Architecture, conventions and native gotchas: [`CLAUDE.md`](../../CLAUDE.md#phone-apps)
- Android dev loop in a container on Linux: `npm run sandbox` (`scripts/android-sandbox.sh`)
- App Store releases: [`docs/ios-release.md`](docs/ios-release.md)
- `android/` is hand-maintained and committed; `ios/` is generated by `npx expo prebuild -p ios` and not committed.
